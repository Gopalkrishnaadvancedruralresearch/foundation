Direct Microstrain (με) Arduino Code 
#include "HX711.h"

// Required Library: "HX711 by Bogdan Necula"
// Install via Arduino IDE: Sketch -> Include Library -> Manage Libraries...

const int LOADCELL_DOUT_PIN = 2; // Data Pin (DT)
const int LOADCELL_SCK_PIN  = 3; // Clock Pin (SCK)

HX711 scale;

// Calibration scale factor for 500 Ohm Quarter Bridge (GF = 2.0, Gain = 128)
// Directly outputs strain in microstrain (ue)
float microstrain_scale_factor = 214.75; 

void setup() {
  Serial.begin(115200);
  while (!Serial) { delay(10); }

  Serial.println("=================================================");
  Serial.println(" GARRF Instrumentation Lab - BRFX-500 Direct Strain ");
  Serial.println("=================================================");

  scale.begin(LOADCELL_DOUT_PIN, LOADCELL_SCK_PIN);

  if (scale.is_ready()) {
    scale.set_scale();
    Serial.println("Zeroing baseline (unstrained 500 Ohm)... Keep sensor unloaded.");
    delay(1500);
    scale.tare(); // Zero offset
    scale.set_scale(microstrain_scale_factor);
    Serial.println("System Ready! Outputting Microstrain (ue)...");
  } else {
    Serial.println("Error: HX711 not detected. Check breadboard wiring!");
  }
}

void loop() {
  if (scale.is_ready()) {
    // Read calibrated microstrain (με) directly
    float microstrain = scale.get_units(5);
    long raw_counts   = scale.read_average(5);

    Serial.print("Raw ADC: ");
    Serial.print(raw_counts);
    Serial.print(" | Strain: ");
    Serial.print(microstrain, 1);
    Serial.println(" microstrain (ue)");
  } else {
    Serial.println("HX711 busy...");
  }
  delay(150);
}

Arduino UNO Digital 3 HX711 Module SCK (Clock) Serial Shift Clock Pulse
HX711 Module E+ (Excitation +) Wheatstone Bridge Top Node (R1 & R2) Regulated Bridge Excitation (+4.3V)
HX711 Module E- (Excitation -) Wheatstone Bridge Bottom Node (R3 & R4) Bridge Ground Reference
HX711 Module A+ (Analog +) Wheatstone Bridge Left Node (R1 & BRFX R3) Active Half-Bridge Signal
HX711 Module A- (Analog -) Wheatstone Bridge Right Node (R2 & R4) Reference Half-Bridge Signal

Help File & Strain Formulas

For a quarter-bridge arrangement with nominal resistance R0 = 500 Ohms, Gauge Factor GF = 2.0, and excitation voltage Vex:

V_A+ = Vex * [ R3 / (R1 + R3) ]
V_A- = Vex * [ R4 / (R2 + R4) ]
V_diff = V_A+ - V_A-
At balance (500 Ohms on all 4 arms): V_diff = 0.000 mV

Delta_R = R3 - 500.0 Ohms
Strain (ε) = (Delta_R / R0) / GF
Microstrain (με) = Strain * 1,000,000
