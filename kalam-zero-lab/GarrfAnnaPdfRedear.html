📖 GUIDE — How to use Prof. GARRF-Anna

Teacher-led offline classroom for research papers. Read this once, then explore.

1. Offline & privacy

  • Files never leave your device. PDF / Word stay in the browser. No server upload of your papers.
  • Press 🔖 Save offline to download a copy of this app and bookmark the page (Ctrl+D / Cmd+D).
  • Basic mode works fully offline after the page and libraries are loaded once.
  • Optional AI (⚙) only talks to your proxy URL — never put an API key in this page.

2. Add papers (+ ADD)

  • Press + ADD PDF / Word (top bar). You can select multiple files at once.
  • Each paper joins the Library bar. Click a chip to switch the active paper.
  • Offline Class is per active paper. Ask searches all papers in the library.
  • Use Clear (active only) or Clear all when finished.

3. Left side — the PDF (click to teach)

  • Click a heading, paragraph, figure caption, table caption, or equation on the page. The professor explains that target on the right board.
  • Section chips under the page controls jump to major headings.
  • Use page ◀ ▶ and zoom − + on the left toolbar.
  • Figure / Table chips in the nav open those media quickly.

4. Right side — professor board & controls

  • Continue ▶ — next teaching step for the current target.
  • ◀ Previous / ↻ Repeat — move among steps; 🔊 Read Aloud speaks the current step.
  • ⏸ Pause / ⏹ Stop — control speech.
  • 📝 Generate Compact Summary — short extractive summary of the active paper.
  • Ask box — type a question; it searches your whole library. 🎤 Speak for voice input / commands (continue, previous, repeat, stop, pause, summary).
  • Level (UG / PG / PhD / Faculty), accent, OCR lang (English + major Indian languages), voice, and speed are in the top settings row.

5. Offline Class (full lecture mode)

  • 🎓 Offline Class (UG) — clearer, shorter classroom path.
  • 📚 Offline Class (PG / Faculty) — denser seminar-style slides.
  • In class: Start → listen; Pause; Prev / Next; Restart; Exit.
  • Right pane shows the PDF page. Use zoom and 🔍 Magnifier (hover or click) when a figure, table, or equation is hard to read.
  • 🖼 Figures / 📊 Tables open a gallery of only those items.

6. Figures, tables, equations on the board

  • The system crops the region from the PDF. Captions may be above or below — density decides the band.
  • Equations are shown as a direct PDF crop (not reconstructed text). Prefer the image.
  • Speech skips equation numbers, list numbers, and page numbers. Dense property lists, specimen dimensions, and material dumps are not read aloud — the board shows a short pointer and you look at the table/PDF crop.
  • Long experimental-setup / fabrication paragraphs are taught as a short story (e.g. sandwiched beam + embedded PZT), not every curing clause.
  • Equations: the professor points to derivation and purpose; symbols are not read (one hearing is not enough to own an equation).
  • Numbers on the board may appear in [brackets] for clarity.
  • Numbered lists stay as clean items. If a crop looks incomplete, check the live PDF (zoom / magnifier).

7. What PDFs work best

  • Works well on downloaded journal, conference, and textbook PDFs (text-based).
  • Scanned / image-only pages need OCR (select language in the top bar). First OCR load needs internet once; then offline.
  • Broken font encoding (θ for “ti”, □ boxes, “RRR” garbage) is cleaned where possible; if text is still wrong, use OCR lang or the live PDF.

8. Indian languages (OCR & speech)

  • Use the OCR lang dropdown (top settings) when the PDF is in Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Marathi, Gujarati, Punjabi, or Urdu (or English + one of these).
  • Speech accent already includes Indian English. Device must have the matching voice installed for best quality.
  • OCR language packs download on first use of that language (needs internet once).

⚠ Disclaimer — accuracy

This tool is for study and teaching support. Parsing of PDFs (especially scanned or complex layouts), OCR, and auto-generated slides can miss or mis-crop content. Equations and tables may be incomplete on the board.

Always verify important facts, numbers, equations, and citations directly in the original PDF or Word file. GARRF and the authors are not responsible for mistakes arising from parsing or summarisation. Use this as a guide, not as a substitute for reading the source.
