Ex 01: Onboard LED (Pin 13) Blink

Directly program the microcontroller digital output to cycle the onboard indicator light.

[ Target Microcontroller: ATmega328P ]
(+) POWER RAIL (-) GROUND RAIL
void setup() { pinMode(13, OUTPUT); // Configure digital pin 13 as output } void loop() { digitalWrite(13, HIGH); // Turn 5V ON delay(1000); // Wait 1 second digitalWrite(13, LOW); // Turn 5V OFF delay(1000); // Wait 1 second }
