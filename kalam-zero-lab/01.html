📚 Learn Before You Build

Ohm's Law describes the relationship between voltage, current and resistance in a resistive circuit.

V = I × R
V = Voltage in volts (V)
I = Current in amperes (A)
R = Resistance in ohms (Ω)

If voltage is known and resistance is known:

I = V / R

🔌 Understand the Virtual Circuit

The basic experimental concept is:

  • Potentiometer → variable input
  • Arduino A0 → reads the analog value
  • Arduino → calculates voltage/current
  • 220 Ω resistor → load resistance
  • LED → visual indication
  • Serial Monitor → displays measurements

🧠 Student Challenge

1. If voltage stays constant and resistance increases, what happens to current?
Current decreases because I = V/R.
2. A 5 V supply is connected to a 1 kΩ resistor. What is the current?
I = 5 / 1000 = 0.005 A = 5 mA.
3. What happens to current if resistance is reduced while voltage remains constant?
Current increases.
4. Why should you change one variable at a time during an experiment?
So that you can identify which variable caused the observed change.
