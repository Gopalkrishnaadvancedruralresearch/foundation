4 Strain Gauges

Mechanical bending creates micro-strain: Tension arms ($R_1, R_3$) increase in resistance while compression arms ($R_2, R_4$) decrease.

Bridge Differential Formula:
VOUT = VEX × [ R3 / (R3 + R4) − R2 / (R1 + R2) ]

10-bit Arduino analogRead() vs 24-bit HX711:

Standard Arduino 10-bit ADC provides 4.88 mV steps ($5\text{V}/1024$). Since full 3 kg load outputs only $10\text{ mV}$, direct `analogRead()` yields only ~2 total steps over the entire range! The HX711 provides 24-bit resolution for precise gram-level measurements.

3. Arduino C++ Starter Code 

#include "HX711.h"
#define DOUT_PIN 2
#define CLK_PIN  3

HX711 scale;

void setup() {
  Serial.begin(9600);
  scale.begin(DOUT_PIN, CLK_PIN);
  scale.set_scale(420.0); // Calibration factor
  scale.tare(); // Zero scale
}

void loop() {
  Serial.print("Weight: ");
  Serial.print(scale.get_units(5), 3);
  Serial.println(" kg");
}

1. How to Use This Interactive Simulation First

Before assembling physical hardware, study the virtual lab to understand force-to-voltage relationships:

  1. Set Target Maximum Load: Click "Setup Max Load" in top menu and enter your intended maximum weight capacity (e.g., 3.0 kg or custom up to 5.0 kg).
  2. Observe +10% Headroom Margin: Notice how the simulator automatically adds $+10\%$ scale headroom (e.g., 3.3 kg max) so you can test overload safety limits without clipping digital bounds.
  3. Drag the Applied Weight Slider: Observe how mechanical pressure bends the Wheatstone bridge, changing strain gauge resistances (R1, R2, R3, R4) and generating micro-volt differential outputs (V_OUT).
  4. Follow the HX711 Signal Path: Trace the signal through the 128x Programmable Gain Amplifier (PGA) up to the 24-bit Delta-Sigma ADC count (8,388,608 to 16,777,215).
  5. Log Experimental Trials: Click "Log Trial Point" at various weight positions to build a linear calibration curve and export the CSV log for report writing.

2. Understanding Physical Load Correlation (Load ↔ ADC Integer)

Students often ask: "Can a serial reading on my computer or smartphone screen be correlated back to physical load, or does a physical load produce a unique reading?" Both directions are directly correlated due to gauge factor linearity!

Direction A: Calibration Step

Applying a known physical weight ($W_{known}$) creates a predictable strain shift, outputting a specific raw 24-bit ADC integer ($ADC_{raw}$).

Calibration Factor = (ADC_raw - Tare_Baseline) / Weight_known
Direction B: Measurement Step

Once calibrated, placing an unknown object yields a raw integer reading that your program instantly converts to exact weight.

Weight_calc = (ADC_observed - Tare_Baseline) / Calibration_Factor

3. How to Build & Customize Arduino Code for Real Load Cells

To build a physical scale with your 3 kg or 5 kg load cell and HX711 board, follow these modifications in Arduino IDE:

  • Install the official "HX711 Arduino Library" by Bogde via Arduino Library Manager.
  • Connect HX711 DT to Arduino Pin 2 and SCK to Pin 3.
  • Perform zeroing (scale.tare()) with an empty weighing platform.
  • Adjust the calibration_factor float parameter until displayed output matches your reference test mass.
#include "HX711.h"

// 1. DEFINE DIGITAL PINS CONNECTED TO HX711
#define DOUT_PIN 2  // Data Out pin from HX711
#define CLK_PIN  3  // Serial Clock pin from HX711

HX711 scale;

// 2. ADJUST THIS CALIBRATION FACTOR DURING CALIBRATION
// Increase if output reading is higher than actual mass
// Decrease if output reading is lower than actual mass
float calibration_factor = 420.0; 

void setup() {
  Serial.begin(9600);
  Serial.println("Initializing Gopalkrishna Foundation Scale...");

  scale.begin(DOUT_PIN, CLK_PIN);
  
  // Reset scale to zero (Tare out empty platform weight)
  scale.set_scale();
  scale.tare(); 
  
  Serial.println("Zero completed. Place known weight to verify correlation.");
}

void loop() {
  // Apply calibration factor to convert raw ADC counts to kilograms
  scale.set_scale(calibration_factor);

  Serial.print("Correlated Weight: ");
  Serial.print(scale.get_units(5), 3); // Average 5 readings for stability
  Serial.println(" kg");

  delay(300);
}
