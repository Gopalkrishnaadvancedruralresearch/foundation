❓ Charan Das Desktop Companion Guide

📱 24/7 Desk Buddy Setup Guide

  1. Deploy & Launch: Put index.html alongside the friend/ folder. Host via GitHub Pages or local web server.
  2. Enable Stay Awake (Android): In Developer Options, turn on "Stay Awake" so the screen never dims while plugged into USB power.
  3. Battery Protection: In Settings → Battery, enable "Protect Battery" (caps charge at 80–85% for safe continuous docking).
  4. Connect DB: Tap anywhere to awaken. Charan Das will connect to your friend/ folder and say "Thank you!" once connected.
