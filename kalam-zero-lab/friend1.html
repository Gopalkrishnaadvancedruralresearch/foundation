❓ Charan Das Desktop Companion Guide

📱 24/7 Desk Buddy Setup Guide

  1. Deploy & Launch: Save this file as index.html alongside the friend/ folder in your repository. Host via GitHub Pages.
  2. Enable Stay Awake (Android): Go to Settings → About Phone, tap Build Number 7 times. Then in Developer Options, turn on "Stay Awake" so the screen never sleeps while plugged in.
  3. Battery Protection: In Settings → Battery, enable "Protect Battery" (caps charge at 80–85% to protect the battery 24/7).
  4. Awaken & Dock: Place phone on a desktop stand. Tap once anywhere on screen to enable camera gaze tracking and continuous speech listening.
