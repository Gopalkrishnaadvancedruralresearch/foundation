📖 Prof. AI Acharya User Guide & Instructions

1. Visual & Hardware Image Inspection

Upload circuit photos, experimental setups, or graphs using ➕ Add Files / Images. Connect a free Gemini API key to have Acharya decode components, wiring connections, resistors, and sensor readings.

2. Spreadsheets & Statistical Analysis

Upload any .xlsx, .xls, or .csv file (e.g., student marks or experimental loads) and ask:

  • "Who is the class topper?"
  • "What is the class average?"
  • "Show highest and lowest scores."

3. Word & PowerPoint Summarization

Upload .docx or .pptx files and ask "summarize this document" or "explain the slides" for an automated breakdown.

4. Voice Input & Indian Voice Readout

Click 🎤 Voice Input to speak directly. Toggle 🔊 Voice: ON/OFF to control spoken responses. When answers are extensive, Acharya provides a concise summary and offers to read the complete breakdown.

5. Offline Privacy & Security

All file parsing runs locally inside your browser memory. Documents are not permanently stored on any external server.
