A modern online laboratory for ECE and EEE students. Learn electrical circuits, digital logic and embedded programming through guided experiments and browser-based virtual hardware.

No physical components are required to begin. Students can experiment with virtual boards and components, write programs, observe outputs and investigate signals before moving to physical hardware.

🔬 What Students Can Explore

GPIO ADC PWM UART I²C SPI Timers Interrupts Sensors Displays Motors IoT Wi-Fi Logic Gates AC/DC
Important: The virtual circuit should behave as an actual simulated electronic circuit. The GARRF page should not pretend that illustrated HTML components are real electrical components. The current simulator ecosystem supports actual virtual microcontrollers and components, making it suitable as the simulation layer for this laboratory. Wokwi documents support for Arduino, ESP32, STM32 and Raspberry Pi Pico platforms, along with many sensors and peripherals.
Advanced option: Students can also work with real firmware files. For example, Wokwi's documented project configuration supports HEX/ELF for Arduino Uno/Mega, HEX/UF2/ELF for Pico, BIN/UF2/ELF for ESP32, and HEX/BIN/ELF for STM32.
ESP32 / IoT: The ESP32 simulation can also use virtual Wi-Fi for IoT experiments involving HTTP, MQTT and related networking experiments.

🌱 GARRF Laboratory Philosophy

The purpose of this laboratory is not simply to make a circuit "work". Students should understand the relationship between theory, circuit, program, measurement and physical engineering behaviour.

The virtual environment allows students to make mistakes safely, repeat experiments and investigate embedded systems before working with physical hardware.

The laboratory can subsequently be expanded with additional Arduino boards, ESP32 variants, Raspberry Pi Pico, STM32, sensors, displays, motors, communication buses and IoT experiments.
