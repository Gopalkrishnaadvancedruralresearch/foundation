👨‍🎓 HOW TO USE THE GARRF LAB
STEP 1 — SELECT EXPERIMENT
Choose an experiment from the catalog.

STEP 2 — SELECT BOARD
Choose Arduino UNO, Nano, Mega, ESP32, Raspberry Pi Pico or STM32.

STEP 3 — BUILD CIRCUIT
Connect the virtual components to power, ground and signal pins.

STEP 4 — WRITE PROGRAM
Use the C/C++ programming editor.

STEP 5 — COMPILE
Press COMPILE. The GARRF compiler service can then compile the sketch using the appropriate board toolchain.

STEP 6 — GENERATE FIRMWARE
The compiler should return the appropriate firmware:
Arduino UNO / Mega → HEX / ELF
Raspberry Pi Pico → HEX / UF2 / ELF
ESP32 → BIN / ELF / UF2
STM32 → HEX / BIN / ELF

STEP 7 — LOAD FIRMWARE
Load the generated firmware into the selected virtual board.

STEP 8 — RUN SIMULATION
Start the embedded simulation.

STEP 9 — MEASURE
Use the virtual voltmeter, ammeter, oscilloscope, logic analyzer and serial monitor.

STEP 10 — LEARN
Compare theoretical and simulated results and complete the experiment.
