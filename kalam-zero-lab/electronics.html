Welcome to the GARRF Virtual Engineering & Robotics Laboratory — a progressive environment where students can move from fundamental electronics to embedded systems, IoT, autonomous robots, robotic arms, humanoids, quadrupeds and AI-enabled machines.

The GARRF engineering pathway is: THEORY → DESIGN → CIRCUIT → CODE → COMPILE → SIMULATE → TEST → ANALYSE → IMPROVE

For robotics experiments, students are supported by CHITTI — the GARRF Robotics AI Assistant, designed to guide learning, experimentation, troubleshooting and project development.

👨‍🎓 How to Use the Virtual Laboratory

  1. Choose one of the 50 experiments.
  2. Select the virtual controller.
  3. Ask CHITTI if you need guidance.
  4. Enter the selected virtual laboratory.
  5. Build the circuit or robotic system.
  6. Write or modify the program.
  7. Compile and run the simulation.
  8. Observe sensors, motors, displays and outputs.
  9. Record your observations.
  10. Change parameters and investigate what happens.
