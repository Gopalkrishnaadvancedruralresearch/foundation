1. Interfacial Adhesive Shear-Lag & Viscoelastic Boundary Mechanics

In physical structural health monitoring installations, the piezoceramic transducer is bonded to the host structure through an adhesive layer (typically cyanoacrylate or high-shear epoxy) of finite thickness tb. The adhesive acts as a viscoelastic boundary interface that transmits dynamic stress into the substrate through interfacial shear stress τ(x):

τ(x) = ( G̅b / tb ) • [ usubstrate(x) − uPZT(x) ]
Complex Shear Modulus: G̅b = Gb ( 1 + j ηb )
Complex Shear-Lag Parameter: Γ = √( G̅b / ( tb • Y̅11E • h ) )

Here, Gb is the storage shear modulus (0.5 to 3.0 GPa), ηb is the viscoelastic loss factor (0.02 to 0.30), Y̅11E = Y11E(1 + jη) is the complex Young's modulus of PZT, and h is transducer thickness.

Modified Effective Structural Impedance Z̅s,eff

Due to interfacial shear lag, the mechanical drive-point impedance Zs presented by the host substrate is filtered before reaching the electro-active ceramic core. The effective impedance Z̅s,eff coupled to the PZT element is governed by:

Z̅s,eff = ( G̅b / ( Γ • tb ) ) • tanh( Γ • l ) • [ Zs / ( Zs + Zbond ) ]
Bond Transmission Efficiency Factor: αbond = tanh( Γ • l ) / ( Γ • l )
  • Thick or Soft Adhesive ($t_b \uparrow$, $G_b \downarrow$): A thick adhesive layer increases mechanical compliance between PZT and substrate. This attenuates high-frequency shear stress transmission, reducing resonance peak heights and broadening the half-power bandwidth (reducing effective system $Q$-factor).
  • Viscoelastic Dissipation ($\eta_b \uparrow$): Higher adhesive loss factors introduce damping into the boundary impedance, elevating the baseline conductance floor without altering structural modal frequencies.

2. Structural Geometry & Analytical Modal Dynamics

The natural frequencies and mechanical drive-point impedances of the host structure are calculated strictly from analytical elastodynamics based on the selectable dimensions:

  • Length ($L$): 50 mm to 1000 mm (metals), 50 mm to 500 mm (concrete).
  • Width ($W$): Constrained between 1/5 L and 1/2 L (0.20 L ≤ W ≤ 0.50 L), ensuring valid beam and plate aspect ratios.
  • Thickness ($t_s$): 2 mm to 6 mm for 1D/2D thin formulations ($t_s \ll L, W$); 10% L to 100% L for 3D volumetric solids.
1D Euler-Bernoulli Flexural Base:    fbase,1D = ( βn2 / ( 2π L2 ) ) • √( E • I / ( ρ • A ) ) = ( βn2 / ( 2π L2 ) ) • √( E / ρ ) • ( ts / √12 )
2D Kirchhoff-Love Thin Plate Rigidity:    D = ( E • ts3 ) / [ 12 • ( 1 − ν2 ) ],    fbase,2D = ( π / ( 2 L2 ) ) • √( D / ( ρ • ts ) )
3D Volumetric Continuum Base:    cs = √( E / [ 2 • ρ • ( 1 + ν ) ] ),    fbase,3D = cs / ( 2 • √( L2 + W2 + ts2 ) )

4. Comparative Admittance Formulations: 1D, 2D, and 3D

A. 1D Formulation [Liang, Sun, & Rogers, 1993, 1994]

Assumes pure uniaxial extension along length l (T2 = T3 = 0):

Y(ω) = jω ( w l / h ) • [ ε̅33T − d312 Y̅11E + d312 Y̅11E • ( Za,1D / ( Z̅s,eff + Za,1D ) ) • ( tan(κl) / (κl) ) ]

B. 2D Formulation [Zhou et al., 1996; Bhalla & Soh, 2004]

Biaxial plane stress (T3 = 0) with Poisson's ratio ν cross-coupling and adhesive shear-lag:

Y(ω) = 2 jω ( w l / h ) • [ ε̅33T − ( 2 d312 Y̅E / ( 1 − ν ) ) + ( 2 d312 Y̅E / ( 1 − ν ) ) • ( Za,2D / ( Z̅s,eff + Za,2D ) ) • ( tan(κl) / (κl) ) ]

C. 3D Directional Sum Impedance [Annamdas & Soh, 2007, 2008]

Captures full 3D stress-strain tensors across all six faces without planar assumptions:

Y(ω) = jω ∫∫A D • n dA = G(ω) + j B(ω)
Total Boundary Impedance: Zs,3D = Zs,xx + Zs,yy + Zs,zz + Zshear
Directional Wavenumbers: κx = ω √( ρ / C11E ),    κy = ω √( ρ / C22E ),    κz = ω √( ρ / C33E )
High-Frequency Thickness Mode Proof: When impedance sweeps reach 600–900 kHz, physical measurements display a pronounced thickness dilatation resonance peak. Because 1D and 2D models enforce T3 = 0, their wave equations lack the ∂2uz/∂z2 eigenvalue, rendering them mathematically incapable of predicting this mode. The 3D Annamdas-Soh formulation incorporates κz = ω √(ρ / C33E), predicting the thickness peak within 2% to 4% of measured experimental data.
