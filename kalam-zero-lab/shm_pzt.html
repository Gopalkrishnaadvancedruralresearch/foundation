PART 2 — SIMULATED DAMAGE

Experiment concept

Electrical excitation drives the PZT. The bonded patch creates mechanical waves in the structure. A defect changes propagation, reflection, scattering and the sensed electrical response. The same simulated response is sent to Part 4.

EXPERIMENT SESSION

Run Healthy first for the selected monitoring duration. Then select a damage condition, choose severity, and run again. The session retains the Healthy → Damaged workflow for ARJUN.
